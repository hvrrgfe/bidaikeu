# 「笔袋复刻」高考助考数据搜集项目

> 目标：复刻「笔袋」高考志愿填报App（除社区外的全部核心功能），全免费、支持用户导入API。本目录为数据搜集与整理成果。

## 📦 项目位置：`/var/minis/shared/bidaikeu/`

## 已搜集数据总览

### 📁 data/gaokao/ —— 高考制度与地区数据
- ✅ `各省高考制度.md` — 31省高考模式（3+1+2 / 3+3 / 旧高考）、总分、科目、时间、赋分规则
- ✅ `各省录取分数线.md` — 2023-2025年各省特控线/本科线/专科线（物理类+历史类）
- ✅ `各省批次结构与志愿规则.md` — 院校专业组/专业+院校、"冲稳保"、平行志愿、特殊类型
