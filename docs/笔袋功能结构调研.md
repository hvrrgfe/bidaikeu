# 笔袋App 真实功能结构调研（2026-08-01 实访）

> 来源：真实访问笔袋官网（gaojiua.com）及 H5 网页版（gaojiua.com/h5/）记录。
> 笔袋 = 高就啊科技（北京）有限公司开发的高考志愿填报App，slogan"考同样的分数，上更好的大学"。

## 一、底部导航（5个Tab）
**首页 / 共享空间 / 填志愿 / 学习 / 我的**

## 二、首页功能模块（真实截图确认）

### 志愿填报类
1. **填志愿**（核心入口）— 显示 可冲击/较稳妥/可保底 数量 + 志愿表数
2. **一句话志愿** — 输入一句话描述需求，AI生成志愿建议
3. **填报志愿** — 完整志愿填报流程
4. **查分填报** — 出分后按分数填报

### 查询类
5. **找学校** — 院校库搜索（路由：`#/gaokao/university/list/index`）
6. **查专业** — 专业库搜索
7. **省批次线** — 各省批次线查询
8. **一分一段** — 分数段/位次查询
9. **野鸡大学** — 野鸡大学查询/警示
10. **成绩查询** — 各省教育考试院查询入口

### 生涯规划类
11. **心理测评** — 职业兴趣/性格测评
12. **挑职业** — 职业库
13. **薪资查询** — 职业薪资数据
14. **强基计划** — 强基计划专题

### 排行榜类
15. **合成清北排行榜**
16. **高校特色榜**
17. **奇妙排行榜**
18. **大学排行榜**
19. **专业排行榜**

### 资讯类
20. **高考日程** — 高考关键日程
21. **新闻中心** — 各省考试院新闻动态（实时更新）

## 三、填志愿核心流程（真实操作确认）
1. 进入"填报志愿" → 跳转 `#/gaokao/application/setting`
2. 填写：**高考省份**（可选全国）、**高考年份**、**选学科**（物理/历史2选1 + 化学/生物/政治/地理4选2）、**高考分数**、**高考排名**（可自动匹配）
3. 系统按分数+选科+省份自动匹配排名（如"2026年650分排名区间：107~114"）
4. 完成后进入志愿推荐（需手机号登录）→ 生成 冲/稳/保 志愿表

## 四、查大学页面结构（`#/gaokao/university/list/index`）
- 顶部Tab：**查大学 / 查专业**
- 筛选：搜索学校、所在地区、院校类型
- 学校卡片：名称、城市、公办/民办、类型（综合/理工）、标签（985/211/双一流/教育部直属/强基计划）
- 分页加载更多

## 五、查专业页面
- 按学科门类筛选（本科/专科、工学/理学/医学/经济学/管理学/法学/历史学/教育学/农学/文学/艺术学/哲学/交叉学科）
- 按专业类筛选（计算机类/电气类/自动化类/电子信息类等）
- 搜索专业名称

## 六、付费模式（用户要求去除）
- **高考志愿填报卡 ¥168永久**（含志愿方案/录取概率/风险评估 + 赠4年打印会员）
- 会员对比：普通用户 vs 志愿填报卡（精准匹配、概率分析、风险分析、测评推荐、薪资招聘分析为付费权益）
- **用户需求：全免费 → 复刻版去掉付费墙，全部功能免费**

## 七、技术栈观察
- H5版为 **uni-app（Vue）** 框架编译
- 路由格式：`#/gaokao/xxx/xxx`
- 用户体系：手机号+验证码登录
- 数据源：自建数据库 + 各省考试院新闻聚合
